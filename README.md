# 🎲 Jogo do Número Secreto  
Um simples e divertido jogo desenvolvido com **HTML**, **CSS** e **JavaScript**, onde o jogador tenta adivinhar um número gerado aleatoriamente.

---

## 🚀 **Funcionalidades**
- Geração de um número secreto aleatório.
- Feedback ao usuário (se o número é maior ou menor).
- Interface amigável e responsiva.
- Mensagens dinâmicas para vitória ou tentativa incorreta.

---

## 🎮 **Como Jogar?**
1. Acesse a [demonstração online](https://jogo-do-numero-secreto-omega-five.vercel.app/).
2. Tente adivinhar o número secreto digitando um valor.
3. O jogo te dirá se o número é **maior** ou **menor**.
4. Continue até acertar! 🎉

---

## 🛠️ **Tecnologias Utilizadas**
- **HTML**: Estrutura da página.
- **CSS**: Estilização da interface.
- **JavaScript**: Lógica e interatividade do jogo.
